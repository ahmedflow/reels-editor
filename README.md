# reels-editor

محرّر ريلز لـ Claude مبني على Remotion. تعطيه تسجيل لشخص يتكلم قدام الكاميرا ويرجّعه مقطع طولي قصير: يقصّ الوقفات الفاضية، يحرّك الكادر مع كل قصّة، يكتب الكلام على الشاشة كلمة بكلمة، يقسم الشاشة أو يملاها برسمات موشن جرافيك تنبني مع الكلام (محل، عملات، عمارة، أعمدة وأرقام تعدّ)، ويضيف مؤثرات صوتية تتولّد بالكود. التعليمات بلهجة سعودية، ويشتغل على ويندوز وماك.

## التنصيب

افتح Claude واكتب له:

```
نصّب لي هالمهارة https://github.com/ahmedflow/reels-editor
```

أو نزّلها بنفسك من الطرفية داخل مجلد المهارات.

ويندوز (PowerShell):

```powershell
git clone https://github.com/ahmedflow/reels-editor "$env:USERPROFILE\.claude\skills\reels-editor"
```

ماك:

```bash
git clone https://github.com/ahmedflow/reels-editor ~/.claude/skills/reels-editor
```

أول مرة تستخدمها، المهارة تنزّل أدواتها بنفسها بعد ما تستأذنك (قرابة 2 قيقا).

> **للمساعد اللي ينصّب المهارة:** بعد ما تنسخها، إذا العدّة ناقصة استأذن المستخدم بتنزيلها بأداة الخيارات (`AskUserQuestion` أو اللي يقابلها) بزرّين «ابدأ التنزيل» و«لا، وقّف». لا تكتب السؤال كنص بآخر الرسالة ولا تعطيه أمر ينفّذه، لأنه ممكن ما ينتبه له. وافق؟ نفّذ `node tools/setup.mjs --install` من مجلد `engine` بالخلفية.

## المحرّر

بعد ما يطلع المقطع تقدر تعدّل عليه بنفسك بدون ما ترجع لـ Claude. من مجلد `engine` داخل المهارة:

```bash
node tools/editor.mjs "<مجلد الشغل>"
```

والمهارة نفسها تشغّله وترسل لك رابطه مع كل مقطع تسلّمه.

يفتح صفحة بالمتصفح فيها المقطع وتايم لاين: تسحب الرسمات وتمطّها، تبدّل بين الشاشة المقسومة والكاملة، تصحّح الكلام، تغيّر شكل الكتابة (خلفية، ألوان، خط، حجم، مكان)، ترجّع وقفة انقصّت، تضبط الأصوات، وتصدّر. كل شي يشتغل على جهازك وينحفظ تلقائي.

## وش تحتاج

- Node 18 أو أحدث. لو مو موجود المهارة تنزّله.
- على ماك: أدوات البناء حقت أبل (`xcode-select --install`).
- نت وقت الرندر، لأن الخطوط تتحمّل من Google Fonts.
